## Fitur

- Menampilkan dashboard aktivitas.
- Menampilkan status aktivitas.
- Melihat detail aktivitas.
- Menampilkan daftar mahasiswa.
- Mencari mahasiswa berdasarkan nama.
- Melihat detail mahasiswa.

## Teknologi

- React Native
- Expo
- JavaScript

## Instalasi

Pastikan Node.js dan npm sudah terinstal.

```bash
npm install
```

## Menjalankan Aplikasi

Menjalankan di browser:

```bash
npx expo start --web
```

Menjalankan melalui Expo:

```bash
npx expo start
```
